# Image Gallery

A modern, fully responsive image gallery with advanced filtering, lightbox view, and image effects.

![Gallery Demo](https://img.shields.io/badge/Status-Active-brightgreen)
![License](https://img.shields.io/badge/License-MIT-blue)

## ✨ Features

- 🖼️ Responsive grid layout (auto-fill with minmax)
- 🎨 Category filtering (Nature, Architecture, People, Abstract)
- 🎭 Image effects (Grayscale, Sepia, Blur, Brightness)
- 🔍 Lightbox modal with smooth animations
- 📸 Thumbnail strip for quick navigation
- 🎯 Image counter and information display
- ⌨️ Keyboard navigation support
- 🛡️ Error handling with placeholder images
- 📱 Mobile-optimized responsive design
- ✨ Smooth animations and transitions
