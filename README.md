# Image Gallery

A responsive image gallery built with HTML, CSS, and JavaScript. Browse images by category, apply visual effects, and view photos in a lightbox.

## Features

- Responsive image grid layout
- Category filters for Nature, Architecture, People, and Abstract
- Grayscale, sepia, blur, and brightness effects
- Lightbox modal with smooth animations
- Thumbnail navigation and image counter
- Smooth transitions and hover effects
- Placeholder handling for failed images
- Keyboard navigation support

## How to Use

1. **Browse Images** – Images are displayed in a responsive grid layout. Hover over any image to see the view option.

2. **Filter by Category** – Click the filter buttons at the top to view images by category:
   - Click "All Photos" to see all images
   - Click "Nature" for landscape photos
   - Click "Architecture" for building photos
   - Click "People" for portrait photos
   - Click "Abstract" for artistic images

3. **Apply Image Effects** – Check the boxes below the filters to apply effects:
   - Check "Grayscale" to remove colors
   - Check "Sepia" for a vintage brown tone
   - Check "Blur" for a soft focus effect
   - Check "Brightness" to increase light
   - You can combine multiple effects

4. **View in Lightbox** – Click any image to open it in full-screen mode:
   - Use arrow buttons on the sides to navigate
   - Click thumbnails at the bottom to jump to a specific image
   - View the image counter to see your position
   - Hover over the image to see its title and category

5. **Close Lightbox** – Click the X button in the top-right corner or press Escape.

## Keyboard Shortcuts

| Key | Action |
| --- | --- |
| `←` | Previous image |
| `→` | Next image |
| `Escape` | Close the lightbox |

## Getting Started

1. Clone or download this repository
2. Open `index.html` in a modern web browser
3. An internet connection is needed to load the sample images
